# Slack Bot
it is a bot that runs 24/7 on a Nest server, this is my second project in hack club

//The commands are whose start with "/"

# Functions
Well, this robot has many functions as 
- Weather (/bohrbot-weather): Introduce your city and an API would tell you the weather 
- Facts about chuck Norris(/bohrbot-chucknorris): Probe it!
- Bot ping(/bohrbot-ping): That's to check if the bot in the server is running 
- Jokes(/bohrbot-joke): Tells you a bad joke 
- Cat Fact(/bohrbot-catfact): A little fact about cats
- Facts about space(/bohrbot-randomspacefact): I did blocks so slack can renderize images 
- Greeting(/bohrbot-hello)
